# indian-etf-risk-analyzer

Comparing NSE-listed Indian ETFs on return and risk using Python and SQL.

## Data
Six Nippon India ETFs, daily prices from Jan 2021 via Yahoo Finance:
Nifty 50, Nifty Bank, Nifty Next 50, Nifty IT, Gold and Long-term G-Sec.

## Tools
Python (pandas, numpy, yfinance), SQLite, Google Colab
